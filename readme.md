## Key Features

<div style="border-left: 4px solid #0078D7; background: rgba(0,120,215,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;"><b>Real-Time Linting:</b><br>

Continuously scans your source files using <b>GCC</b>/<b>G++</b> in syntax-check mode.  

Highlights warnings and errors directly inside the editor with colored markers and annotation bubbles.  

Seamlessly syncs error highlights with the <code>plugin.acode.minimap</code> plugin for precise visual indicators.

</div>

<div style="border-left: 4px solid #28A745; background: rgba(40,167,69,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;">
<b>Code Execution Runner:</b><br>

Four run modes: <b>Terminal</b>, <b>Popup</b> (bottom toast), <b>Inline</b> (ghost logs next to <code>printf</code>/<code>cout</code>), and <b>Inline input</b> (inline logs + input chips stdin).<br>

Compile-time / run-time feedback, optional timing &amp; exit code, multi-file link, automatic cleanup.<br>

Errors in inline mode open a formatted bottom popup (file:line, error/warning colors).

</div>

<div style="border-left: 4px solid #20C997; background: rgba(32,201,151,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;">
<b>Input chips (stdin):</b><sup style="background:#ff9c24;border-radius:10px;padding:2px 8px;color:#fff;">new</sup><br>

Small chips on <code>scanf</code> / <code>cin</code> / <code>fgets</code> / <code>getline</code> lines — <b style="color:#05962d;">DOUBLE-TAP</b> to enter values.<br>

<b>Sequential prompts</b> (not space-separated): one popup per variable showing <code>&amp;name</code>, datatype, and format (<code>%d</code>, <code>%f</code>, …).<br>

Supports multi-arg <code>scanf("%d %d %f", &amp;a, &amp;b, &amp;c)</code> and <code>cin &gt;&gt; a &gt;&gt; b</code>.<br>

Settings: clear-on-type, block run if missing, chip preview count (default 5, max 10), max loop inputs (default 100).

</div>

<div style="border-left: 4px solid #6610F2; background: rgba(102,16,242,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;">
<b>Loop-aware input:</b><sup style="background:#ff9c24;border-radius:10px;padding:2px 8px;color:#fff;">new</sup><br>

Detects <code>for</code> / <code>while</code> / <code>do-while</code> and estimates iteration count for constant bounds.<br>

Fill modes: <b>one-by-one</b>, <b>same value for all</b>, <b>numeric range</b> (start→end, step; pad with last), <b>pattern</b> (<code>+2</code>, <code>*2</code>, <code>-1</code>…).<br>

Chip shows <code>↻N: v1 · v2 · …</code> (preview count from settings).<br>

<b>Variable-bound loops:</b> e.g. <code>scanf("%d",&amp;b)</code> then <code>for(i=1;i&lt;=b;i++)</code> — when <code>b</code> is set, loop chips auto-refresh to <code>b</code> rounds (repeats prior single value if any).

</div>

<div style="border-left: 4px solid #0DCAF0; background: rgba(13,202,240,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;">
<b>Inline run logs:</b><sup style="background:#ff9c24;border-radius:10px;padding:2px 8px;color:#fff;">new</sup><br>

Maps program stdout to the matching <code>printf</code>/<code>cout</code> line (handles prompts without <code>\n</code>).<br>

Newlines shown as <code>↵</code>

### ⚙ Settings Options

#### `clangFormatStyle`
Specifies the base formatting style.  
Accepts any of the standard presets supported by `clang-format`, such as:

- `LLVM`
- `Google`
- `Mozilla`
- `WebKit`
- `Chromium`
- `GNU`

**Example:**
```
clangFormatStyle: 'Google'
````

---

#### `clangFormatCustom`
Allows defining a **custom formatting style** using JSON or YAML syntax.
Paste your own style definition directly into this `text area` in settings.

You can combine it with the base style for fine-tuning indentation, brace style, and spacing.

**Example (YAML):**

```
BasedOnStyle: LLVM
IndentWidth: 8
TabWidth: 4
BreakBeforeBraces: Allman
AllowShortIfStatementsOnASingleLine: false
IndentCaseLabels: true
```

  <img src="https://i.postimg.cc/sD1P228K/1761209522734.png" alt="C/C++ Tools Example" style="width:200px;border-radius:5px;">

**Example (JSON):**

```
{
  "BasedOnStyle": "Google",
  "IndentWidth": 8,
  "TabWidth": 4,
  "UseTab": "Never",
  "BreakBeforeBraces": "Allman",
  "AllowShortIfStatementsOnASingleLine": "false",
  "IndentCaseLabels": "true"
}
```

#### Default Configuration

Defined in `settings.js`:

```
const defaultSettings = {
  ...
  clangFormatStyle: 'Google',
  clangFormatCustom: '',  <-- Add custom formatter here
};
```

## <span style="background: linear-gradient(135deg, #052138, #194063); -webkit-background-clip: text; -webkit-text-fill-color: transparent; font-weight: bold;">C++ Smart Auto Header Import</span>

<div style="border-left: 4px solid #2196F3; background: rgba(33,150,243,0.08); padding: 10px 15px; border-radius: 6px; margin: 10px 0;">
<b>Header Management (Experimental)</b><br>
This feature uses <b>Tree-sitter</b> parsing to intelligently detect C++ functions, STL objects, and I/O streams in your source file.  
It automatically updates your <code>#include</code> statements — keeping them clean, minimal, and always relevant.
</div>

### How to Enable

Go to:
**Acode → Settings → C/C++ Tools → Enable Advanced Analysis (Tree-sitter)**

Once enabled, Auto Import will start managing your includes dynamically based on file changes.

---

### Features & Settings

| Setting                      | Description                                                                                                                                                                                             | Default     |
| :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------- |
| **`autoImportTrigger`**      | Controls *when* the auto-import engine runs.<br>• `onSave` — Runs only when you save.<br>• `onKeypress` — Runs after 2.5s of inactivity.                                                                | `'onSave'`  |
| **`removeUnusedHeaders`**    | Handles headers that are no longer in use.<br>• `Do Nothing` — Keep as-is.<br>• `Comment Out` — Turns `#include <vector>` into `// #include <vector>`.<br>• `Remove Line` — Deletes the unused include. | `'comment'` |
| **`autoImportNewlineStyle`** | Adjusts spacing between newly inserted headers.<br>• `Compact` — No extra line breaks.<br>• `Spaced` — Adds one blank line between groups.                                                              | `'noSpace'` |

---

### Smart Logic

This C++-optimized system is both **context-aware** and **non-intrusive**:

* **Adds Missing Headers:** Detects identifiers like `cout`, `vector`, or `string` and auto-imports `<iostream>`, `<vector>`, or `<string>`.
* **Reuses Existing Ones:** If `<string>` was commented out, it will automatically uncomment instead of re-adding.
* **Cleans Up Unused Headers:** When functions or STL containers are removed, unused headers are safely commented or deleted.
* **Recognizes `using namespace std`:** Understands context and avoids confusion between local identifiers and STL names.
* **Prevents Duplicates:** Ensures no repeated `#include` lines appear in the file.
* **Optimized for C++17/20 syntax:** Supports smart parsing of lambdas, templates, and standard containers.

## Troubleshooting

**Issue:**  
> "gcc: not found"

**Solution:**  
Run the following inside the Acode terminal (Termux container):
```
apk update
apk add gcc g++ bc 
````

If unavailable, install manually via:

**Issue:**

> Linter shows garbage commands before header

**Solution:**
The latest release uses a shared terminal manager to keep the output clean and correctly ordered.
Update your plugin from the latest `dist` build.

**Issue:**

> Already downloaded dependencies still coming popup

**Solution:**
Just cancel & ignore
